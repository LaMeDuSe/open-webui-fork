# LaMeDuSe AI Branding Assets

This directory contains the LaMeDuSe AI branding assets: favicons, logos, splash images, app icons, and web app manifest icons.

The Open WebUI branding originally shipped here has been replaced with LaMeDuSe branding under written permission from Open WebUI. The upstream `LICENSE` file is kept unchanged.

- `lameduse-ai-logo.svg`: official LaMeDuSe AI logo (https://assets.lameduse.net/logo/lameduse_ai_logo_grad_text_primary_bg_none.svg), for light backgrounds.
- `lameduse-ai-logo-dark.svg`: same logo with the text in white, for dark backgrounds.
- `favicon.svg`: official LaMeDuSe siglet (https://assets.lameduse.net/logo/lameduse_siglet_grad.svg).

Official sources for all LaMeDuSe logos: https://assets.lameduse.net/logo/
